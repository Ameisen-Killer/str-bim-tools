# STR Bim Tools

Extension pyRevit pour les ingénieurs structure, pour Revit 2024 et versions suivantes : métré CAN 241, quantification, export IFC et nomenclatures, gestion des réservations.

Site : <https://str-bim-tools.com>

Ce dépôt contient le site vitrine, publié avec GitHub Pages depuis le dossier `docs/` de la branche `main`.
