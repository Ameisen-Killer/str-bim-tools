    Seules les valeurs changées sont écrites. Ce qui est partagé avec d'autres objets (type Revit, solide commun) est copié avant : seuls les éléments visés changent. Les quantités (Qto) ne sont pas recalculées.

    Propriété

    Un champ laissé tel quel ne change rien ; vidé, il efface la valeur.

    Classe IFC

    Nom, placement, forme, matériau et propriétés sont gardés ; le type prédéfini repart à « non défini ». Portes et fenêtres perdent leurs dimensions propres.
