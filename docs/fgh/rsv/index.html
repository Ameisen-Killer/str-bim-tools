Validation des réservations

Glisse ici les deux IFC exportés par le bouton Revit « Export IFC RES » (dossier FGH) :

  1. …_RES.ifc : les demandes de réservation, avec leurs paramètres ;
  2. …_STR_light.ifc : la structure, pour voir ce que chaque réservation traverse.

Choisis une réservation, valide-la ou refuse-la. Tes décisions partent dans un fichier JSON que le modeleur applique dans Revit avec « Import Validation RES ».
